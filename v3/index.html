00 / BEFORE YOU PLAY

事前準備：先組好自己的牌組

每位玩家都要帶一副合法牌組和一組六顆委託骰。可以自行組牌，也可以使用符合規則的預組牌組；這裡介紹一般構築賽規則，特殊賽制（例如現開賽）可能不同。

卡牌顏色與 RAM 限制

卡牌分為紅、綠、藍、黃四種顏色。先選好 3 張不同名稱的傳奇卡，再把它們提供的 RAM 依顏色分開相加，就能知道主牌組每種顏色的 RAM 上限。

舉例：三張傳奇卡各提供 2 RAM
綠色 2 + 2 = 4紅色 2

如果選兩張綠色傳奇卡、一張紅色傳奇卡，就能放入 RAM 4 以下的綠色卡及 RAM 2 以下的紅色卡；藍色、黃色的 RAM 上限則是 0。若三張都是紅色，紅色上限就是 2 + 2 + 2 = 6。

RAM 是單張卡牌的組牌門檻，不是牌組 RAM 總額。例如綠色上限為 4，代表每張綠色卡各自的 RAM 不能超過 4，不是所有綠色卡的 RAM 加起來只能有 4。RAM 也不是出牌時消耗的費用；出牌使用的是 €$。

準備卡牌

3 張傳奇卡：名稱不能重複，獨立於主牌組。辨認方式是看卡面右上角的 Legend 類型標示；Iconic 是版本／稀有度，不能只憑 Iconic 判定為傳奇卡。40～50 張主牌組：不含傳奇卡；同名、同副標題的卡最多 3 張。主牌組的顏色與單張 RAM 數值必須符合三張傳奇卡提供的各色 RAM 上限。

準備委託骰

每人各準備 6 顆委託骰：四面骰（d4）、六面骰（d6）、八面骰（d8）、十面骰（d10）、十二面骰（d12）、二十面骰（d20），各 1 顆。

開局擺放

STEP 01

決定先後手、各自洗勻主牌組，將 3 張傳奇卡隨機蓋放在傳奇區。

STEP 02

把六顆骰子依 d4 → d6 → d8 → d10 → d12 → d20 放在合事佬區。

STEP 03

抽 6 張起始手牌，可調度一次；先手玩家最左兩張傳奇卡開局為已使用。

注意：40～50 張是「主牌組」張數，不是起始手牌；3 張傳奇卡也不會放進主牌組抽取。官方詳細規範：Comprehensive Rules ↗

02 / 卡牌類型與支付資源認識四類卡牌，以及 €$ 的用途
CARD TYPES

先認識四類卡牌

傳奇卡（Legend）決定牌組核心與 RAM 限制；單位卡（Unit）負責戰鬥，裝備卡（Gear）強化角色，程式卡（Program）則帶來一次性效果。看卡面右上角的 Legend 類型標示才能辨認傳奇卡；Iconic 是特殊版本／稀有度，兩者不是同一件事。

PAYMENT

出牌需要資源

用歐元（Eddies／€$）支付卡牌費用。主要階段每回合可以變賣 1 張具有變賣標籤的手牌；傳奇區內的傳奇卡也能橫置支付，每張算 1 €$。完整支付操作仍待正式對戰引擎加入。

REFERENCE / RULEBOOK

RULES CODEX.

先記住兩件事

勝利條件委託骰至少 7 顆

一般情況下，在自己回合開始時持有至少 7 顆委託骰就獲勝。看的是骰子的數量。

卡牌能力常用條件街頭聲望＝骰子點數總和

三顆骰子擲出 2、4、6 點：街頭聲望是 12，但委託骰只有三顆。

教學內文統一使用中文；中英對照僅保留在下方術語表。實體卡牌與卡圖上的文字仍是官方英文，規則裁定以官方版本為準。

開局與回合順序

一般構築賽由玩家自行準備合法牌組：3 張不同名傳奇卡，另外搭配 40～50 張主牌組（每種同名同副標題最多 3 張，須符合顏色與 RAM 限制），並準備 d4、d6、d8、d10、d12、d20 各一顆。開局先決定先後手，再洗勻主牌組、隨機蓋放傳奇卡、把六顆委託骰放到合事佬區，最後從主牌組抽 6 張，可調度一次。

先手玩家最左邊 2 張傳奇卡開局為已使用，第一回合不會重置。每回合依序：重置 → 抽 1 張 → 取得 1 顆委託骰 → 主要階段。在主要階段可變賣、出牌、呼叫傳奇與攻擊。

關鍵行動與觸發時機

呼叫傳奇（Call a Legend）：每回合最多一次，支付 1 €$ 將一張隨機蓋放的傳奇卡翻開；在對手攻擊的反應時機也能呼叫。CALL：當這張傳奇卡透過呼叫傳奇被翻開時觸發。

PLAY：打出卡牌時。ATTACK：單位宣告攻擊時、對手反應前。DEFEATED：單位被擊敗時。獨武俠（GO SOLO）：支付傳奇卡費用，將其當作就緒的單位部署，當回合即可攻擊；若離開戰場則移出遊戲。

傳奇區內面朝上或面朝下的傳奇卡，都能橫置支付 1 €$，但傳奇卡不算歐元。加時賽：最後行動玩家的第 7 回合結束後開始；加時期間只要持有至少 7 顆委託骰，立即獲勝。

術語中英對照

骰子記法（d4～d20）＋

「d」代表骰子，後面的數字代表面數。例如四面骰（d4）可以擲出 1～4 點。

四面骰（d4）、六面骰（d6）、八面骰（d8）、十面骰（d10）、十二面骰（d12）、二十面骰（d20）。二十面骰必須最後才擲。

合事佬區（Fixer Area）＋

每回合用來取得新委託骰的區域；開局時，自己的委託骰都放在這裡。

每回合開始抽牌後，從合事佬區選 1 顆骰子擲出；20 面骰必須最後才擲。

委託骰（Gig Die）＋

委託由骰子代表；勝利時看的是持有幾顆委託骰，而不是點數有多高。

一般回合開始時，自己的委託區若有至少 7 顆委託骰，就獲勝。

街頭聲望（Street Cred）＋

把自己委託區所有骰子的點數相加，得到街頭聲望。

持有 3 顆骰子，點數是 2、4、6，街頭聲望是 12；委託骰數量仍是 3 顆。

就緒（Ready）＋

卡牌處於直立、尚未被使用的狀態。

就緒不代表一定能攻擊：剛登場的角色仍可能受到 Lag 的限制。

已使用（Spent）＋

卡牌橫置 90 度，表示這張卡目前已用過。

角色攻擊、使用資源付費或使用特定能力時，會把對應卡牌橫置。

新登場限制（Lag）＋

剛打出的角色即使處於就緒狀態，當回合也不能攻擊或啟動需要橫置自己的能力。

等到這個回合結束後，新登場限制才會解除。

戰力（Power）＋

角色交戰時比較的數值；攻擊對手委託區時也決定可以搶幾顆骰子。

戰力 1–9 可搶 1 顆，10–19 可搶 2 顆；戰力 0 搶不到。

攔截（Blocker）＋

具有這項能力的就緒角色，可以橫置自己，把原本的攻擊轉向自己。

攔截後改成角色交戰；這一次攻擊就不能搶委託骰。

交戰（Fight）＋

比較雙方角色的戰力；低的一方被擊敗，戰力相同則雙方都被擊敗。

戰力 4 對戰力 2，戰力 2 的角色會被擊敗。

出牌資源（Eddies，€$）＋

支付卡牌費用時使用的資源。每回合最多能賣出一張符合條件的手牌，變成 1 個資源。

有需要時也能橫置傳奇角色，將其作為 1 個資源支付。

傳奇卡（Legend）＋

每副牌的 3 張核心角色卡，開局放在專用區域並保持蓋著。

每回合最多一次，可以支付 1 個資源，隨機翻開一張傳奇角色。

單位卡（Unit）＋

出牌後會留在場上的角色，可以交戰，也可以攻擊對手委託區搶骰子。

剛出場時有新登場限制（Lag）。

裝備卡（Gear）＋

裝在己方角色或符合條件的傳奇角色上的卡牌。

像螳螂刀（Mantis Blades）就會提高戰力。

程式卡（Program）＋

使用時支付費用並結算卡牌效果，通常結算後就放入棄牌區。

某些程式具備 Quick，可以在特定反應時機使用。

快速反應（Quick）＋

特定時機可以在對手回合或對手攻擊時使用的能力或卡牌效果。

完整快速反應窗口尚未納入目前的練習引擎。
