# V3 參考桌面分布與直式開局（2026-11-07）

本輪依使用者提供的其他網站截圖調整桌面分布與資訊層次。圖片僅作視覺參考；遊戲仍使用現有引擎及已核對規則，未套用截圖中的 Overtime 等規則文字。

## 桌面

桌機改四欄、八列 CSS Grid：

- 左欄：對手手牌 → 對手合事佬 → 對手委託 → 獨立回合狀態 → 我方委託 → 我方合事佬 → 我方手牌。
- 中央：上方對手三張傳奇及 Eddies、上下雙方戰場、下方我方三張傳奇及 Eddies。
- 戰場右緣窄列：對手 Trash／牌庫、我方牌庫／Trash；不再佔用整個寬欄。牌庫數字與 Trash 入口連動實際狀態，抽牌按鈕仍在我方牌庫。
- 最右欄：上方對局控制、中段行動紀錄、下方當前階段／結果／結束回合等全局操作。

左側回合狀態顯示實際 ROUND、階段與我方／等待對手；對局控制使用原本認輸、離開及引導事件，沒有假的多人房間或聊天操作。出牌、支付、攻擊、Quick／Blocker 及能力選擇仍保留上輪的卡牌／場地直接操作。

行動紀錄只收錄成功且回傳新狀態的遊戲命令，不把 hover、選牌、取消選取或教學步驟當遊戲行動。紀錄帶回合與行動方、保留本局最近八十段；使用者閱讀舊紀錄時保留捲動位置。對手變賣只顯示蓋牌，不將原卡名寫入可見紀錄或結果摘要。切換設定／重新開局清除本局紀錄。

## 開局與提示

- 開局恢復一行一個選單，寬 510px、高度隨內容，不再固定 570px 留大塊空白。六張起手確認仍可使用較寬橫排。
- 對手說明、固定手牌名稱使用可展開的補充資訊，保留開局規則與必要提示；先後攻及保留／重抽維持左右按鈕。
- 引導使用參考圖的層次：步驟、標題、說明、醒目的下一步指示、可展開的規則／名詞與官方規則連結。
- 支援收合／展開、桌面說明上一步／下一步、略過及關閉。收合不推進教學或遊戲；實戰提示仍由真實狀態自動更新。
- 黃色桌面說明與青色實戰引導保持區分。區域改統一深藍底與圓角框，主要按鈕維持平面實色。
