# V3 可讀性、直式開局與骰子時機（2026-11-07）

依五張操作截圖與補傳的 34.4 秒參考錄影調整。已檢視錄影中的開局保留、選牌變賣、逐張付款、單位進場、結束回合及對手行動；沿用既有規則引擎，未照抄參考網站的牌組或新增未核對效果。

- 開局全部維持窄直式，含先／後攻、六張起手、保留／重抽及開始對戰。六張牌用直列縮圖與名稱／費用列，可點擊查看完整卡面。較短畫面在卡牌列表內捲動，確認按鈕仍在下方。
- 委託區重新分列：標題與 0/7 在上、街頭聲望一列、實際骰值以 chip 顯示。刪除重複顆數指示；骰值容器有自己的空間與必要溢位捲動，不再被場地邊界裁掉。
- 增加左側與中央遊戲區、縮窄右側紀錄。可見介面文字至少 12px；主要操作 14px，付款進度／擲骰 16px。操作按鈕至少 44px 高。卡面內印刷字體不受 CSS 字級規則影響，仍可用預覽閱讀能力。
- 選取手牌使用完整 3px 青色框及「✓ 已選」，選取牌置頂至 500、hover 牌為 501。保留不移動、不上浮的原則與穩定命中區域。
- 雙方手牌按實際可用寬高計算重疊量，使用整個手牌欄；resize 重新量測，不更換選牌或付款狀態。對手手牌數量仍來自遊戲狀態。
- 擲骰區位置保留。擲骰按鈕常駐，只有玩家準備階段的 roll 步驟、尚有合法骰且沒有待結算能力時可按；其他情況為灰色 disabled。骰子選擇同步停用，d20 最後使用的限制保留。
- 付款區在選牌後強調可支付來源，Eddie 與傳奇按鈕共同排列、已選來源用粗框。卡牌旁顯示「付款進度 n / 費用」；確認才由原引擎付款及出牌。情境框改放戰場旁，避免擋住左側聲望／委託資訊。
