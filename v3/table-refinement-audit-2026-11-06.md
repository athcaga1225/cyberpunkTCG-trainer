# V3 手牌命中、固定面板與程式策略（2026-11-06）

## 截圖所指操作修正

- 移除雙方手牌每張卡預設的紅／黃裝飾邊框。玩家選取以底部青色短線標記，鍵盤焦點仍有明確提示。
- hover 不改變手牌圖層順序；以 `elementFromPoint` 取得滑鼠下實際可見的卡牌，點擊與預覽使用同一判定。覆蓋在手牌上方的 UI 不會穿透成卡牌選取。
- 桌面操作區放入右側既有回合格位並填滿，內容過多只在格內捲動，不再依內容改變外框高度。原有大面積診斷面板仍隱藏。
- 已確認起手的「開始對戰」及「重新設定開局」兩個按鈕左右排列，不改動保留／Mulligan 判定。

## 下一階段：主要程式與防守呼叫

沿用[官方 Comprehensive Rules](https://cyberpunktcg.com/comprehensive-rules) 已核對的程式、Quick、Call 與戰鬥時機，不新增未驗證卡文。

- 隨機鏡像 `active` 策略在單位／裝備後，最多再選一張合法主要階段程式。支付資源、目標與抽牌都走既有出牌與效果引擎。
- Afterparty at Lizzie's 指定公開委託骰，按調整後不同點數檢查抽牌；Floor It 指定已支援對手單位、降低 Power 並實際抽牌；Reboot Optics 會在可進行等 Power 交戰時提供保護，策略可選擇該交戰並實際消耗保護。
- 不主動選擇已知會從空牌庫強制抽牌的可選程式，也不以 Floor It 模擬未支援單位的被指定觸發。準備階段等既有強制抽牌仍照常執行並判定落敗。
- 防守 React Step 可支付 1 €$ 呼叫第一個蓋牌位置，不按隱藏卡名挑選；每個玩家回合仍最多一次。完成 Call 的搜尋與支付觸發後，再選 Quick／Blocker 與結算攻擊。
- 防守時呼叫 V 不會執行 Go Solo；防守時呼叫 Viktor 只搜尋加入裝備，不在 React Step 非法裝備。
- 固定手牌練習維持 `basic` 策略；這些新增策略限隨機鏡像／明確選用 active 的測試場面。
